# Система мониторинга и автоматического восстановления для Python-микросервисов

## Описание проекта

Данный проект представляет собой легковесную систему мониторинга и алертинга для Python-микросервисов с функцией автоматического восстановления. Система предназначена для небольших и средних проектов, где развёртывание промышленных решений (Prometheus, Kubernetes) экономически нецелесообразно.

## Основные возможности

- **Мониторинг микросервисов** — периодическая проверка health-эндпоинтов зарегистрированных сервисов
- **Автоматическое восстановление** — перезапуск неисправных сервисов с защитой от частых перезапусков (cooldown-период 30 секунд)
- **Веб-интерфейс** — дашборд с отображением состояния сервисов, страница управления режимами сбоев и журнал восстановления
- **Оповещения** — уведомления в консоль, Telegram и на внешний webhook
- **Хранение данных** — SQLite для хранения метрик, событий восстановления и алертов
