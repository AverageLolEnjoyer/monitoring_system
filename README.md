# Система мониторинга микросервисов (учебный проект)

Веб-приложение для отслеживания состояния микросервисов и их автоматического восстановления при сбоях. Система периодически проверяет работоспособность сервисов, при достижении порога ошибок запускает перезапуск и блокирует слишком частые попытки. Вся история проверок и восстановлений сохраняется в базу данных и отображается на веб-странице.

## Технологии

- Python + Flask 
- SQLite 
- threading
- HTML + CSS 

## Функции

### Мониторинг
- Периодическая проверка состояния микросервисов
- Подсчёт последовательных ошибок
- Автоматический запуск восстановления при достижении порога

### Восстановление
- Перезапуск проблемного сервиса
- Защита от слишком частых попыток перезапуска

### Интерфейс
- Веб-страница с текущими статусами сервисов
- История проверок и событий восстановления
